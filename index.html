### 대화 모드 구분

- 실행 요청 (만들어줘, 작성해줘, 변환해줘 등) : 바로 실행
- 사고/판단 요청 (어떻게 할까, 어떤 방향이 좋을까, 고민이야 등) : 소크라테스 모드

### 소크라테스 모드 규칙

- 바로 답을 주지 말고, 핵심을 짚는 질문을 1개씩 던져라
- 내 답변을 바탕으로 다음 질문으로 깊이를 넓혀라
- 내가 스스로 결론에 도달하도록 유도하라
- 충분히 탐구했다고 판단되면 대화 내용을 요약 정리하라
- 내가 "정리해줘" 또는 "결론 내줘"라고 하면 소크라테스 모드를 종료하고 정리하라

###작업을 시작하기 전에 메모리를 많이 사용할거같으면 미리 경고해줘

### 패션/의류 AI 프롬프트 서브 템플릿

**적용 조건:** 패션 룩, 의상 디자인, 스타일링 이미지 프롬프트 요청 시 자동 적용

**구조 (위→아래 스캔 순서):**
[상의 스펙] → [하의 스펙] → [신발] → [노출/실루엣] → [액세서리] → (선택) [무드 한 줄]

**핵심 원칙:**
1. 아이템별 독립 블록으로 작성 — 각 의류를 별도 문장/단락으로 분리
2. 추상어 제로, 물성 100% — "cool" "stylish" 금지 → 소재(latex, denim, ripstop), 마감(high gloss, matte, distressed), 구조(knee pad panels, side pockets, gathered at ankle)로 대체
3. 무드는 아이템 조합으로 유도 — 직접 분위기를 설명하지 말고 소재+실루엣 조합이 무드를 만들게 할 것. 필요시 마지막에 한 줄 태그만 추가 (예: "street style meets tactical utility")
4. 색상은 대비 명시 — 피부톤과 혼동 가능한 색상(nude, beige, mustard 등)은 "distinctly different from skin tone" 또는 대비 배경색 지정
5. 촬영 조건은 최소화 — 의류 디테일 반영률 우선. 촬영 조건이 필요하면 배경(studio white, concrete floor)과 크롭(full body, waist-up)만 간결하게 추가

**작성 예시:**
```
MIDNIGHT NAVY VELVET BLAZER, DOUBLE-BREASTED, PEAK LAPEL,
SLIGHTLY OVERSIZED FIT, DEEP PILE TEXTURE.

WIDE-LEG IVORY SILK TROUSERS, HIGH WAIST,
FLUID DRAPE, PRESSED CENTER CREASE, NO BELT LOOPS.

BLACK PATENT LEATHER POINTED-TOE ANKLE BOOTS,
STILETTO HEEL, 80MM HEIGHT.

EXPOSED COLLARBONE. MINIMAL JEWELRY — SINGLE THIN GOLD CHAIN.

EDITORIAL MINIMALISM MEETS OLD MONEY QUIET LUXURY.
```

**기존 범용 구조와의 관계:**
- 범용: [촬영방식] + [크롭/구도] + [오브젝트] + [배경] + [앵글] + [빛] + [톤/무드]
- 패션 특화: 오브젝트(의류) 묘사에 올인, 나머지 요소는 필요시에만 최소 추가
- 패션 프롬프트 요청 시 이 서브 템플릿 우선 적용, 촬영/아트 프롬프트는 기존 범용 구조 유지

### 2단계 캐릭터 드레싱 워크플로우

**적용 조건:** 특정 캐릭터/인물에게 디자인한 의상을 입히는 이미지를 생성할 때

**원리:** 관심사 분리 — 1단계에서 의상 레퍼런스를 확보하고, 2단계에서 캐릭터에 이미지 레퍼런스로 이식. 텍스트로 의류 디테일을 반복 서술하지 않는다.

**워크플로우:**

1단계 — 의상 레퍼런스 생성
- 위 패션 서브 템플릿으로 의상 스펙 프롬프트 작성
- 의류 디테일에 올인, 모델/캐릭터는 신경 쓰지 않음
- 결과물: 의상이 명확히 보이는 레퍼런스 이미지 확보

2단계 — 캐릭터 + 의상 합성
- Image 1(캐릭터) + Image 2(1단계 의상 레퍼런스)를 함께 입력
- 텍스트 프롬프트는 촬영 조건만 담당, 의류 디테일은 이미지가 전달
- 프롬프트 구조: [캐릭터 지시] + [의상 지시] + [촬영 조건]

**2단계 프롬프트 예시:**
```
THE CHARACTER FROM IMAGE 1 WEARING THIS OUTFIT FROM IMAGE 2.
FULL BODY SHOT, WHITE STUDIO BACKGROUND,
SOFT CINEMATIC LIGHTING, REALISTIC.
```

**2단계 촬영 조건 옵션 (필요시 선택 추가):**
- 크롭: full body shot / waist-up / three-quarter
- 배경: white studio / concrete floor / solid color
- 조명: soft cinematic lighting / flat studio lighting / dramatic side lighting
- 출력 형태: character sheet (front + back + face close-up) / single pose
- 스타일: realistic / stylized / editorial

**주의사항:**
- 2단계에서 의류 디테일을 텍스트로 다시 쓰지 말 것 — 이미지 레퍼런스와 텍스트가 충돌하면 반영률이 떨어짐
- 캐릭터 시트(다면도)가 필요하면 "character sheet, front view and back view, face close-up" 추가
- 색상 괴리가 1단계에서 발생했을 경우, 2단계에서 캐릭터 피부톤 차이로 자연 보정될 수 있음

### 크리처/오브젝트 디자인 AI 프롬프트 서브 템플릿

**적용 조건:** 몬스터, 에일리언, 판타지 생물, 메카, 무기, 아이템 등 비인간 오브젝트 디자인 프롬프트 요청 시 자동 적용

**구조 (전체→부분→표면 줌인 순서):**
[1블록: 전체 형태/실루엣] → [2블록: 표면 질감/핵심 디테일 + 포즈] → [3블록: 렌더링/촬영 조건]

**핵심 원칙:**
1. 전체→부분→표면 줌인 — 먼저 전체 골격/실루엣을 잡고(arachnid-like body structure), 그 다음 부위별 디테일(serrated limb-blades, armored carapace), 마지막으로 표면 재질(cracked stone-like hide)
2. 추상어 제로, 물성 100% — "scary" "terrifying" 금지 → 구조와 재질로 감정을 유도. 위협감은 jagged spines, serrated blades 같은 물리적 묘사로 전달
3. 혼합 물성(Material Mixing) — 서로 다른 재질을 하나의 표면에 레이어링하여 비현실적 존재감 생성 (예: "hardened shell + wet organic tissue + cracked stone-like hide")
4. 포즈는 자세+방향만 — "low crouching stance, front-facing" 처럼 물리적 자세만 지시. "menacing"은 가능하나 이것도 포즈의 인상 정도로만 사용
5. 렌더링 조건은 프로덕트 렌더 스타일 권장 — "white background, soft shadow beneath, product-render style lighting"으로 디자인 시트처럼 깔끔하게 뽑아낼 것. 배경이 복잡하면 디테일 반영률이 떨어짐

**작성 예시:**
```
A MASSIVE ALIEN CREATURE WITH AN ARACHNID-LIKE BODY STRUCTURE,
MULTIPLE LONG SERRATED LIMB-BLADES SPLAYED WIDE,
HEAVY ARMORED CARAPACE COVERED IN JAGGED SPINES AND ORGANIC PLATING.

GLOWING MOLTEN CORE VISIBLE AT THE CHEST.
TEXTURED SURFACE MIXING HARDENED SHELL,
WET ORGANIC TISSUE, AND CRACKED STONE-LIKE HIDE.
LOW CROUCHING STANCE, FRONT-FACING, MENACING.

WHITE BACKGROUND, SOFT SHADOW BENEATH,
PRODUCT-RENDER STYLE LIGHTING.
HYPER-DETAILED, CINEMATIC REALISM.
```

**혼합 물성 조합 레퍼런스:**
- 유기체: chitin + wet membrane + exposed sinew
- 기계+유기: corroded metal plating + pulsing bio-luminescent veins
- 석재+유기: volcanic rock surface + glowing magma cracks + leathery skin folds
- 결빙: frosted crystal shell + semi-transparent ice + dark fluid underneath

**캐릭터 드레싱 워크플로우와 조합 가능:**
- 1단계에서 크리처 레퍼런스를 확보한 뒤, 2단계에서 특정 씬/환경에 배치하거나 캐릭터와 합성할 수 있음
- 2단계 프롬프트: "THE CREATURE FROM IMAGE 1 IN [환경/씬]. [카메라 앵글], [조명], [스타일]."

### AI 영상/애니메이션 프롬프트 보강 원칙

**적용 조건:** Seedance, Sora, Kling, Runway 등 AI 영상 생성 모델용 프롬프트 요청 시 자동 적용. 기존 영상 구조(SHOT 0X + 카메라무브 + 피사체행동 + 재질디테일 + 라이팅)에 아래 원칙을 추가 적용한다.

**프롬프트 3단계 레이어 구조:**

① 스타일 레이어 — 시각적 언어를 정의
- 예술적 사조/스타일 키워드를 문장 맨 앞에 배치한다
- 예: `2D French graphic novel style`, `stop motion style`, `claymation style`, `low poly, toy`, `ink outlines, screen tone`
- 질감+빛 키워드를 함께 붙여 분위기 일관성 확보: `clay texture, soft morning light`, `moody lighting`

② 서사 레이어 — 초 단위 동작 분해 + 카메라 워크
- 추상적 행동 설명 금지 → 초 단위 동작 시퀀스로 분해
- 나쁜 예: "남자가 도망간다"
- 좋은 예: "남자가 펜스 위를 기어오르고, 당황하며 시계를 두 번 두드리고, 사라지기 직전 1초간 카메라를 응시한다"
- 영화 촬영 용어(Medium shot, Extreme slow-mo, Pan up, Dolly in)를 프롬프트에 포함

③ 일관성 레이어 — 시각적 연속성 유지
- 반복 등장하는 소품(시계, 무기 등)은 별도 프롭 시트(Prop Sheet) 이미지를 만들어 레퍼런스로 투입
- 새 장면 생성 시 이전 영상(Previous Video)을 입력 데이터로 함께 넣어, 캐릭터 외형과 이펙트의 연속성 유지
- 이는 에셋 분리 파이프라인의 시간축 확장 — 공간적 분리(얼굴/의상/배경)뿐 아니라 시간적 연속성도 이미지 레퍼런스로 관리
- 레퍼런스 이미지 콜라주: 캐릭터의 클로즈업 + 전신 샷을 하나의 콜라주 이미지로 만들어 입력하면 AI가 외형을 더 정확히 파악
- 장면 전환 시 프레임 추출: 이전 영상의 마지막 프레임 + 다음 영상의 첫 프레임을 레퍼런스로 추가하여 끊김 방지
- 레퍼런스 이미지 품질이 출력 품질을 결정 — 투입 전 반드시 고화질 업스케일링

**스타일 변환 키워드 레퍼런스:**
- 치비/토이: `low poly, toy, miniature figure`
- 망가: `ink outlines, screen tone, speech bubbles, kanji effects`
- 실사+2D 혼합: `2D character in live action, contrast between flat illustration and photorealistic background`
- 클레이메이션: `claymation style, clay texture, stop motion`
- 그래픽노블: `2D French graphic novel style, bold ink lines, muted palette`

**제작 효율 원칙:**
- 이미지 수정 우선 — 비디오를 새로 생성하기 전에 키프레임 이미지를 먼저 수정(인페인팅)한 뒤 비디오화
- 15초 법칙 — 모든 장면을 15초 이내(안정적 권장 10초)로 유지. 길어지면 AI의 시각적 일관성이 깨지고 편집 복잡도가 급상승
- AI 창의성 활용 — 새 캐릭터나 예측 불가능한 요소는 과도한 지시 없이 상황만 던져주면 앞선 맥락 기반으로 AI가 자체 디자인하도록 유도
- 네거티브 키워드 — 편집 편의를 위해 프롬프트 끝에 "no words", "no music" 등 불필요한 요소 차단 키워드 추가
- 글자수 제한 의식 — 대부분의 영상 모델은 1,500자 내외 제한. 핵심 위주로 작성하되, 넘치면 디테일 vs 자율성 판단 기준에 따라 간결화
- 텍스트는 방향, 이미지는 디테일 — 텍스트 프롬프트는 전체 방향과 액션을 지시하고, 실제 디테일과 일관성은 레퍼런스 이미지로 통제한다

**보강 원칙 1: 물리 법칙 프롬프팅**
- 행동(Action)이 아니라 행동의 물리적 결과(Consequence)를 서술한다
- 상황 설명(Caption)을 금지하고, 충격·반동·무게감·관성·여파를 직접 묘사한다
- 이를 통해 AI가 사실적인 질감, 질량, 운동감을 렌더링하도록 유도한다

나쁜 예 vs 좋은 예:
```
❌ THE MECH PUNCHES THE MONSTER.
✅ THE MECH'S FIST CONNECTS WITH THE MONSTER'S TORSO —
   SHOCKWAVE RIPPLES THROUGH ITS CARAPACE,
   FRAGMENTS OF CHITIN BURST OUTWARD,
   THE MECH'S ARM RECOILS FROM THE IMPACT,
   GROUND CRACKS BENEATH BOTH FROM THE TRANSFERRED FORCE.
```

```
❌ THE GIANT ROBOT WALKS FORWARD.
✅ EACH STEP OF THE MECH SINKS INTO CRACKED ASPHALT,
   DUST PLUMES RISE FROM THE FOOTFALL,
   HYDRAULIC JOINTS HISS UNDER THE SHIFTING WEIGHT,
   NEARBY DEBRIS TREMBLES WITH EACH STRIDE.
```

**보강 원칙 2: 디테일 vs 자율성 판단 기준**
- 모든 샷에 동일한 수준의 디테일을 넣지 않는다
- 아래 기준에 따라 프롬프트의 구체성 수준을 조절한다

디테일을 최대로 넣어야 하는 경우:
- 물리적 충돌/액션 장면 (물리 법칙 프롬프팅 적용)
- 특정 오브젝트의 디자인이 중요한 클로즈업
- 감정 표현이 서사에 핵심인 장면

AI 자율성을 믿고 간결하게 쓸 경우:
- 리듬/음악 기반 동작 (춤, 군무 등) — AI가 리듬감을 자체 해석하도록 유도
- 군중 씬이나 환경 전체를 보여주는 와이드샷
- 전환(Transition) 장면 — 과도한 지시가 오히려 부자연스러운 결과를 만듦

간결한 프롬프트 예시:
```
FIVE CHARACTERS IN SYNCHRONIZED K-POP CHOREOGRAPHY,
DYNAMIC CAMERA CIRCLING THE GROUP,
HIGH ENERGY, STAGE LIGHTING.
```

**보강 원칙 3: 에셋 분리 파이프라인 (다중 캐릭터 프로젝트)**
- 복수 캐릭터가 등장하는 프로젝트에서는 에셋을 분리 생성 후 병합한다
- 얼굴, 의상, 크리처, 메카, 배경을 각각 독립적으로 생성 → 레퍼런스 이미지로 확보 → 최종 씬 합성 시 이미지 레퍼런스로 투입
- 이는 2단계 캐릭터 드레싱 워크플로우의 확장이며, 캐릭터뿐 아니라 세계관 전체 에셋에 동일 원리를 적용한다

에셋 분리 순서:
1. 캐릭터 얼굴 레퍼런스 (각 캐릭터별 독립 생성)
2. 의상 레퍼런스 (패션 서브 템플릿 적용)
3. 캐릭터 + 의상 병합 (2단계 워크플로우)
4. 크리처/메카/소품 레퍼런스 (크리처 서브 템플릿 적용)
5. 배경/환경 레퍼런스 (범용 구조 적용)
6. 최종 씬 합성 — 확보된 이미지 레퍼런스 + 최소 텍스트 프롬프트(카메라/액션/조명)

---

### 프롬프트 요청 시 작동 규칙

**프롬프트를 요청받으면 바로 작성하지 말고, 아래 프로세스를 따른다.**

**Step 1: 유형 판별**
요청을 아래 중 하나로 분류한다:
- A) 패션/의류 → 패션 서브 템플릿 기반 질문
- B) 크리처/오브젝트 → 크리처 서브 템플릿 기반 질문
- C) 영상/애니메이션 → 영상 보강 원칙 기반 질문
- D) 범용 이미지 → 범용 구조 기반 질문
- E) 2단계 워크플로우 (캐릭터 드레싱 / 씬 합성) → 레퍼런스 확인 질문

**Step 2: 핵심 디테일 질문 (1~3개)**
해당 템플릿의 필수 블록 중 빠진 정보를 질문한다. 한 번에 최대 3개까지만 묻는다.

패션(A)일 때 확인할 것:
- 어떤 아이템 조합인지 (상의/하의/신발/액세서리)
- 소재와 마감 (latex, denim, velvet 등 — 물성 수준)
- 전체 무드 방향 (tactical, editorial, streetwear 등)

크리처(B)일 때 확인할 것:
- 전체 실루엣/골격 (곤충형, 파충류형, 기계혼합 등)
- 핵심 물성 조합 (어떤 재질들을 섞을 것인지)
- 용도 (게임 에셋, 컨셉아트, 캐릭터시트 등)

영상(C)일 때 확인할 것:
- 스타일 레이어 (리얼리즘, 클레이메이션, 망가 등)
- 핵심 액션/서사 (무엇이 일어나는 장면인지)
- 카메라 워크 선호 (있다면)

범용 이미지(D)일 때 확인할 것:
- 핵심 오브젝트/피사체
- 분위기/톤 방향
- 용도 (SNS, 포트폴리오, 레퍼런스 등)

**Step 3: 답변 수렴 후 프롬프트 작성**
질문에 대한 답변을 받으면, 해당 템플릿 구조에 맞춰 프롬프트를 작성한다. 추가 디테일이 필요하면 1개씩만 더 묻는다.

**예외: 사용자가 이미 충분한 디테일을 제공한 경우**
요청 자체에 소재, 구조, 스타일, 촬영 조건이 구체적으로 포함되어 있으면 질문 없이 바로 작성한다.

Claude에 Skill 추가하는 법
  1. 영상 설명란에서 Skill 파일(.md) 다운로드
  2. Claude 접속 → 우측 상단 프로필 → Settings
  3. Claude.ai Features → Skills 항목으로 이동
  4. Add Skill 클릭 후 다운로드한 파일 업로드 또는 내용 붙여넣기
  5. 저장 후 Claude 대화창에서 / 를 입력하면 Skill 목록이 나타남
